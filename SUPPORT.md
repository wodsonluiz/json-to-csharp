# Support

For JSON to C# DTO Generator (`wodson.json-to-csharp`), use the
[GitHub issue tracker](https://github.com/wodsonluiz/json-to-csharp/issues)
to report bugs or request features. Search existing issues before opening a new one.

For a bug report, include your VS Code and extension versions, operating system,
steps to reproduce, expected result, actual result, and a small JSON example
with any sensitive or personal information removed. Never include credentials,
tokens, production data, or private project files.
